Làm được 100% trên PWA

1. Quản lý & Phân tích sâu IPA

Đọc cấu trúc ZIP/ZIP64, giải mã Info.plist nhị phân (bplist00), khôi phục ảnh biểu tượng CgBI, đọc nhị phân Mach-O (CPU, khóa DRM FairPlay), giải mã chứng chỉ X.509 & embedded.mobileprovision, đối chiếu UDID và xuất báo cáo kỹ thuật hoàn toàn Offline.

Cần chứng chỉ / Apple ID 0đ

2. Ký số ứng dụng (Code Signing)

Ký nhị phân Mach-O bằng ZSign được tích hợp trong bản IPA Installer Native (SwiftUI). Nếu dùng tài khoản Apple ID cá nhân miễn phí (Personal Team): chứng chỉ có hạn 7 ngày, tối đa 3 ứng dụng đồng thời và 10 App ID mỗi 7 ngày (mỗi .appex trong PlugIns/ tính 1 App ID).

Giới hạn cứng của Safari iOS

3. Tại sao Safari không thể cài IPA 0 đồng trực tiếp?

Tiến trình hệ thống installd của iOS chặn hoàn toàn giao thức web itms-services:// đối với chứng chỉ Development miễn phí. Để cài đặt IPA với chi phí 0 đồng không cần PC, cần khởi tạo tệp ghép đôi (Pairing File) một lần qua cáp OTG bằng Android Termux Bootstrap hoặc chuyển tiếp sang SideStore / LiveContainer.

3 thành phần trong hệ sinh thái dự án

  • A. IPA Installer Web (PWA hiện tại) Cài ngay từ Safari lên màn hình chính, chạy offline, kiểm tra kỹ mọi file IPA trước khi quyết định ký/cài.
  • B. IPA Installer Native (SwiftUI – iOS 15.0 → 26.6+) Biên dịch tự động trên GitHub Actions, phát hành tại GitHub Releases kèm bộ ZSign C++ và kiểm tra chứng chỉ OCSP.
  • C. Android Termux Bootstrap Bộ công cụ chẩn đoán cáp USB-OTG, usbmuxd và libimobiledevice ngay trên điện thoại Android không cần máy tính.
